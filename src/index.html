Transformações formais

Os resultados são criados como novas máquinas na biblioteca; a máquina original permanece intacta.

01

Determinização

Aplica a construção dos subconjuntos, incluindo fecho-ε quando houver transições epsilon. O DFA resultante é completo.

02

Minimização

Remove estados inalcançáveis, completa o DFA com estado poço implícito quando necessário e refina partições de equivalência.

A minimização direta exige um DFA. Para um AFN ou ε-AFN, execute primeiro a determinização. O estado poço pode aparecer na máquina mínima quando for necessário totalizar a função de transição.

GUIA RÁPIDO

Como criar uma máquina

O Automata Playground separa a definição da máquina da regra que a faz funcionar. A definição usa YAML, um formato compacto e legível; projetos antigos em JSON continuam compatíveis e são convertidos quando abertos. Você pode modelar um autômato finito, uma pilha, uma fita de Turing ou qualquer outra estrutura que consiga expressar em JavaScript.

1
Defina o objeto

Edite machine.yaml. O modelo básico usa state, states e alphabet. Acrescente os dados que sua máquina precisar, como stack, tape, head ou memory.

state: q0
states: [q0, q1]
alphabet: ["0", "1"]
acceptingStates: [q1]

transitions:
  q0: { "0": q0, "1": q1 }
  q1: { "0": q0, "1": q1 }
2
Escreva a regra

O código é executado para cada símbolo. Recebe operation, o objeto mutável machine e context. Retorne o identificador do próximo estado. Você pode alterar qualquer outro dado de machine antes de retornar.

const next = machine.transitions[machine.state]?.[operation];
if (next === undefined) throw new Error("Transição não definida");
return next;

O objeto context também oferece step/index (posição do símbolo, começando em 0), input (entrada completa), remaining (símbolos seguintes) e history (snapshots anteriores).

3
Informe a entrada

Para alfabetos de símbolos de um caractere, digite a sequência diretamente. Para símbolos compostos, use um array JSON, como ["push", "pop"]. Todo símbolo precisa pertencer a alphabet.

4
Execute e observe

Use Próximo passo para avançar ou Executar tudo para reiniciar e processar a entrada inteira. O estado null encerra a máquina imediatamente.

Sobre estados e o diagrama

Os estados podem ser strings, números ou objetos com uma propriedade id. As transições presentes em machine.transitions são desenhadas automaticamente. Para regras mais complexas, o diagrama também aprende as conexões observadas durante a simulação. Se houver acceptingStates, o simulador informa se o estado final é de aceitação.

Autômatos não determinísticos

Na tabela convencional, um destino pode ser uma lista de estados. Por exemplo, q0: { a: [q0, q1] } representa duas escolhas para o mesmo símbolo. Transições epsilon podem ser escritas com a chave ε (fora do alfabeto) ou configuradas por epsilonSymbol. Use o Laboratório formal para obter o DFA equivalente pela construção dos subconjuntos.

Laboratório formal

Abra o painel recolhível abaixo do simulador para analisar determinismo, completude, alcançabilidade, estados mortos e componentes fortemente conexas; gerar tabelas; determinizar e minimizar; comparar linguagens; ou converter uma máquina para expressão regular. Essas análises utilizam a estrutura convencional de transitions, não tentam deduzir o comportamento de código JavaScript arbitrário.

Compartilhamento

O link compartilhável leva uma cópia compactada dos dados no fragmento da URL. A pessoa pode abrir, conferir e salvar a máquina na própria biblioteca. Também é possível importar arquivos YAML de máquina ou exportar um projeto completo em JSON.

ⓘ

Regras são código JavaScript. Elas rodam em um Web Worker separado, sem acesso ao DOM ou ao localStorage da aplicação, e com limite de tempo por execução. Só execute máquinas de fontes em que confia.
